# Jadoo

 An attempt to recreate the computer interface from the 2003 movie [Koi Mil Gaya](https://en.wikipedia.org/wiki/Koi..._Mil_Gaya)

 Works on desktop and mobile — on desktop press <kbd>Enter</kbd> and play the notes with the <kbd>B</kbd>–<kbd>F</kbd> keys; on phones and tablets just tap to start and use the on-screen keypad.
